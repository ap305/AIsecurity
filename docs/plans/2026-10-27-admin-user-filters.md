# 用户管理账号筛选计划

**Goal:** 管理员按关键词、账号类型、角色和启停状态筛选账号，保留当前账号管理操作及正式学生服务。

**Design:** 沿用 `/api/admin/users` 已返回的完整数组，使用前端派生结果进行即时筛选；不改变原列表、账号状态、鉴权、数据库和评测逻辑。关键词按空格分词，每个词都要命中用户名/姓名/学校/学号之一（字段间OR、关键词与其他筛选条件AND），忽略英文大小写。正式账号包含管理员，角色单独筛选。空白查询等同全部，已删除账号不展示。重置仅清除筛选，不清空创建表单。

**Scope:** `AdminUser`补充既有DTO的可选studentId；新增小型过滤函数及单元测试；UserManager增加搜索、三组下拉、重置、匹配数量和无结果提示。现有按账号ID进行的创建、启停、重置密码、查看成绩、删除不变，操作刷新后保持筛选。
