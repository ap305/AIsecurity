## 已修复的前端问题

1. **较旧查询覆盖开启结果**：临时教师 API 开启/续期成功后，先前发出的轮询可能晚到并覆盖 active 状态。现在按题目、版本和当前身份隔离请求，以已应用序号和操作屏障处理乱序；切换身份/题目或卸载后旧请求失效。慢查询仍可正常显示，操作进行时不发新轮询，不重复创建租约。
2. **开启/续期无限等待**：原 POST 没有明确超时。现在沿用已有 API 层的 30 秒请求和响应体时限，超时释放按钮，并提供只发 GET 的“重新查询租约”。租约两小时期限、模型额度、服务端评测预算和计分规则均不变。

先增加失败回归，再实现修复，并独立复核。`test:web` 同时补入本轮生命周期测试及原入口遗漏的 SubmissionDiagnostics 测试，显式列表覆盖全部 14 个前端测试文件。
